TECHNOLOGY STACK

The Technology Behind LungScreen AI

A practical combination of machine learning and web technologies that transforms 15 health and lifestyle indicators into an interactive lung cancer risk prediction experience.

01

Python

Powers the machine learning workflow, handles input processing, and connects the trained prediction model with the application backend.

Data Processing Model Integration
02

Scikit-learn

Provides StandardScaler for feature scaling and the Random Forest classifier to estimate lung cancer risk from the input indicators.

StandardScaler Random Forest
03

Flask

Connects the web interface to the Python backend, handles prediction requests, and returns the model's results to the user interface.

Web Framework Prediction Routes
04

Tailwind CSS

Supports a responsive and consistent interface, helping users interact with the lung cancer risk prediction tool across desktop and mobile devices.

Responsive UI Interface Styling
